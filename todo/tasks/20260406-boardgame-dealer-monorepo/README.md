## 需求描述

创建一个 monorepo 风格的桌游发牌器项目，支持多个桌游（如 Avalon、Undercover 等）和多个平台（web、微信小程序、Android、iOS），确保不同项目间 UI 风格一致，并支持通过 AI IDE 进行统一的 UI 风格修改。

### 背景与动机

随着桌游的普及，需要为不同游戏开发发牌器工具。使用 monorepo 架构可以提高代码复用率，确保不同平台和游戏间的 UI 风格一致性，同时通过 AI IDE 提高开发效率和一致性。

### 核心需求

1. **Monorepo 架构**：创建统一的项目结构，管理多个游戏和平台
2. **UI 风格统一**：确保不同游戏和平台的 UI 风格基本一致
3. **多平台支持**：支持 web、微信小程序、Android、iOS
4. **AI IDE 集成**：使用 AI IDE 进行编程，提高开发效率
5. **同步修改机制**：修改 UI 风格时，自动同步到所有项目

### 非功能性需求

1. **可维护性**：代码结构清晰，易于维护
2. **可扩展性**：便于添加新游戏和平台
3. **性能**：各平台运行流畅
4. **一致性**：UI 风格在不同平台和游戏间保持一致

## 实现方案

### 技术方法

1. **Monorepo 管理**：使用 Lerna、Nx 或 Rush 等工具

4. **AI IDE 集成**：使用支持 AI 辅助编程的 IDE
5. **设计系统**：创建统一的设计系统和风格指南
