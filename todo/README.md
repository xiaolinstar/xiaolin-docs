# TODO 任务管理系统

本文件夹采用规范驱动开发原则，每个任务独立管理。

## 文件结构

```
todo/
├── README.md              # 本文件，整体待办完成过程
├── tasks/                 # 所有任务文件夹
│   ├── YYYYMMDD-任务名/   # 每个任务一个文件夹
│   │   ├── README.md      # 任务说明和需求
│   │   ├── plan.md        # 实现方案
│   │   ├── progress.md    # 实现过程记录
│   │   ├── verify.md      # 验证标准
│   │   └── summary.md     # 任务总结
│   └── ...              # 更多任务
└── templates/             # 任务模板（可转化为 skill）
    ├── feature.md
    ├── bug.md
    └── optimization.md
```

## 任务命名规范

**文件夹命名格式**：`YYYYMMDD-任务简述`

**示例**：
- `20260331-baidu-analytics` - 百度统计接入
- `20260401-content-distribution` - 内容分发自动化
- `20260402-paid-consultation` - 付费咨询功能

## 任务生命周期

1. **创建任务**：在 `tasks/` 下创建新文件夹
2. **需求分析**：编写 `README.md` 说明需求
3. **方案设计**：编写 `plan.md` 设计实现方案
4. **开发实施**：在 `progress.md` 中记录实现过程
5. **验证测试**：按 `verify.md` 中的标准验证
6. **总结复盘**：在 `summary.md` 中总结经验
7. **归档完成**：在本文件中记录完成状态

## 技能转化

`templates/` 中的模板可以转化为 skill 技能，实现：

1. **自动生成任务文件夹**：根据模板创建任务结构
2. **任务状态管理**：自动更新任务状态
3. **进度追踪**：实时记录实现进度
4. **验证检查**：自动检查验证标准

## 使用建议

1. **任务独立性**：每个任务文件夹完全独立，避免相互影响
2. **过程记录**：详细记录实现过程，便于复盘
3. **及时更新**：每完成一个步骤立即更新文档
4. **定期回顾**：每周回顾已完成任务，总结经验
5. **模板复用**：充分利用模板，提高效率
