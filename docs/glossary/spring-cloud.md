Spring Cloud 是大型分布式与微服务架构下的事实工业标准。它在 Spring Boot 快速构建单体应用能力的基础上，提供了全套分布式系统治理组件，帮助开发者与运维团队解决微服务调用、服务发现、集中配置与容灾治理难题。
