---
id: portability
term: 可移植性
en: Portability
aliases:
  - 可迁移性
definition: 系统或配置在不同环境（操作系统、云平台、硬件）之间迁移的难易程度，是 ISO 25010 定义的六大软件质量特性之一。
enabled: true
---

系统或配置从一套环境平移到另一套环境的能力。可移植性差意味着环境配置高度依赖具体平台（如特定 Linux 发行版、特定云厂商），换机或迁云时需重新踩坑。Docker 等容器技术的核心价值之一即提升可移植性。参见 [ISO/IEC 25010](https://iso25000.com/index.php/en/iso-25000-standards/iso-25010)。
