# 真心话大冒险

真心话大冒险是聚会助手里门槛最低的游戏，2 人即可开局，适合冷场破冰、等菜间隙和散场收尾。不需要复杂规则讲解，点开就能玩。

## 适合场景

- **人数**：2–12 人；
- **时长**：不限，随时可停；
- **氛围**：轻松、互动、破冰；
- **新手友好度**：★★★★★

## 规则速览

玩家轮流抽取「真心话」或「大冒险」卡片，完成挑战或选择跳过。聚会助手负责抽卡、展示题目、记录进度和收集反馈。

## 完整使用流程

### 1. 进入游戏

首页点击 **真心话大冒险** → 进入设置页。

### 2. 选择模式与风格

| 设置项 | 选项 | 说明 |
| ------ | ---- | ---- |
| 游戏模式 | 混合 / 真心话 / 大冒险 | 混合模式随机抽两种类型 |
| 风格标签 | 轻松 / 朋友 | 轻松适合普通朋友局；朋友适合熟人小聚 |
| 玩家人数 | 2–12 人 | 影响轮流顺序，不影响题目内容 |

#### 模式说明

- **混合**：真心话 + 大冒险随机出现，适合大多数场景；
- **真心话**：聊天破冰为主，偏问答；
- **大冒险**：轻任务互动，可能有简单动作挑战。

#### 风格说明

- **轻松**：适合普通朋友和饭桌局，题目偏日常；
- **朋友**：适合熟一点的小聚，题目可以更深入但仍保持安全。

当前题库全部标记为 `risk=safe`，经过审校，避免低俗、冒犯或隐私风险过高的内容。

### 3. 开始游戏

点击「开始游戏」→ 进入游戏页面。

### 4. 轮流抽卡

流程：

1. App 提示当前轮到哪位玩家（显示座位号或姓名）；
2. 当前玩家点击抽卡；
3. 展示题目内容；
4. 玩家选择 **完成** 或 **跳过**；
5. 自动轮到下一位玩家。

### 5. 题目反馈

如果觉得某道题目不合适，可以点 **「这题不合适」** 并选择原因：

- 无聊 / 不好玩；
- 尴尬 / 不适合当前场景；
- 其他原因。

反馈以匿名方式上报（只含题目编号和原因，不含题目全文），帮助改进题库。网络失败时不影响继续游戏。

### 6. 结束或继续

- 没有固定局数限制，玩够了随时结束；
- 返回设置页可换模式或风格再开；
- 返回首页换其他游戏。

## 题库说明

当前题库规模 72 张，分布如下：

| 类型 | 标签 | 数量 |
| ---- | ---- | ---- |
| 真心话 | 轻松 | 20 张 |
| 真心话 | 朋友 | 16 张 |
| 大冒险 | 轻松 | 20 张 |
| 大冒险 | 朋友 | 16 张 |

题目经过多轮审校：

- 减少「在座谁……」类尴尬题；
- 补充破冰、回忆、轻动作等类型；
- 全部保持安全级别，适合线下朋友聚会。

## 使用技巧

### 冷场破冰

聚会刚开始大家还不太熟时：

- 选 **混合模式 + 轻松风格**；
- 先玩 5–10 分钟热场；
- 有人觉得尴尬可以随时跳过，不必强迫完成。

### 熟人局

朋友认识较久时：

- 可以试 **朋友风格**；
- 大冒险模式带来更多互动；
- 仍建议尊重不愿作答的玩家。

### 灵活收尾

散场前 10 分钟不适合开阿瓦隆这类长局，真心话大冒险可以随时开始、随时结束。

### 与谁是卧底搭配

```text
真心话大冒险（15 分钟破冰）→ 谁是卧底（2 局热场）→ 正式桌游
```

## 隐私说明

- 开局时可能上报匿名事件（游戏类型、模式、人数），**不含玩家姓名**；
- 题目反馈只上报题目编号和原因，**不含题目全文**；
- 游戏过程不上传服务器。

详见[隐私与反馈](../privacy-feedback.md)。

## 常见问题

### 题目重复怎么办？

题库会随版本更新扩充。当前 72 张题重复概率较低，玩久了可能遇到——可以换风格标签或模式。

### 可以自定义题目吗？

当前版本不支持用户自定义题目，目的是保证内容质量和安全审校。有建议可通过反馈渠道提交。

### 有人拒绝回答怎么办？

跳过是正常操作，不要强迫。聚会的目的是开心，不是惩罚。

### 大冒险安全吗？

当前题库全部 `risk=safe`，大冒险以轻度互动为主（如「用三个词形容今晚」），不含危险或冒犯性任务。
