# 一夜狼人

一夜狼人是聚会助手里推理深度与时长平衡较好的游戏，3–8 人即可开局，一晚定胜负。最大特点是 **App 自动主持夜晚流程**，不需要真人主持人。

## 适合场景

- **人数**：3–8 人；
- **时长**：单局约 20–30 分钟；
- **氛围**：推理、紧张、信息量大；
- **新手友好度**：★★★☆☆

## 规则速览

每位玩家获得一个角色（狼人、预言家、强盗、捣蛋鬼等），经历一个夜晚和一天。夜晚各角色按顺序执行私密行动（查看身份、交换身份等），白天讨论并投票处决一名玩家。好人和狼人阵营根据最终身份判定胜负。

与经典狼人杀不同，一夜狼人**只有一晚**，节奏更快，适合聚会时间有限时玩。

## 核心交互：App 自动主持

聚会助手最重要的设计是 **没有人需要当主持人**：

```text
App 提示「请所有玩家闭眼」
  → 当前角色玩家睁眼拿起手机
  → 完成私密操作
  → 放回手机并闭眼
  → App 提示下一个角色
  → 重复直到夜晚结束
  → 白天讨论和投票
```

### 为什么需要闭眼

夜晚行动的乐趣来自信息不完全。如果其他玩家能看到谁拿起手机、谁操作了什么，游戏会失效。线下需要玩家配合闭眼——这是聚会默契，App 通过流程提示来辅助。

## 完整使用流程

### 1. 进入游戏

首页点击 **一夜狼人** → 进入设置页。

### 2. 调整设置

| 设置项 | 说明 |
| ------ | ---- |
| 玩家人数 | 3–8 人，角色组合随人数推荐 |
| 角色包 | 使用推荐角色配置 |

### 3. 开始发牌

点击「开始游戏」→ 传手机查看初始身份。

### 4. 传手机查看身份

1. 按座位号传递手机；
2. 每位玩家**长按**查看自己的角色；
3. 全部看完后进入夜晚流程。

### 5. 夜晚流程（App 主持）

夜晚由 App 逐步引导，每个角色行动分三个阶段：

#### 公开指引页（全员可睁眼）

App 显示类似文案：

```text
下一步：预言家行动
请所有玩家确认后闭眼。
预言家请在所有人闭眼后睁眼并拿起手机。
```

所有人可以看到「接下来轮到哪个角色」，但不知道谁是这个角色。

#### 私密操作页（仅当前角色）

当前角色玩家：

1. 确认其他玩家已闭眼；
2. **长按进入行动**；
3. 根据角色完成操作（查看身份、交换牌等）；
4. 完成后信息自动隐藏。

不同角色的操作不同：

| 角色 | 夜晚能力 |
| ---- | -------- |
| 狼人 | 查看其他狼人；仅 1 狼时可查看一张中央牌 |
| 预言家 | 查看一名玩家身份，或两张中央牌 |
| 强盗 | 与一名玩家交换身份并查看换来的身份 |
| 捣蛋鬼 | 交换两名玩家的身份（不查看结果） |
| 酒鬼 | 与中央牌交换身份（不查看结果） |

#### 遮挡交接页

操作完成后，当前角色放回手机，App 提示下一步。

### 6. 白天讨论与投票

夜晚结束后，App 引导进入白天：

1. 全员睁眼，讨论昨晚发生了什么；
2. 轮流发言（线下进行）；
3. 投票处决一名玩家；
4. 在 App 里记录投票结果。

### 7. 结算

- 根据最终身份判定好人或狼人获胜；
- 可查看夜晚行动回顾；
- 再开一局或返回首页。

## 使用技巧

### 闭眼配合

这是一夜狼人体验的关键。建议：

- 公开指引页时全员睁眼看提示；
- 提示「请闭眼」后所有人闭眼；
- 只有被点名的角色睁眼操作；
- 操作完立刻放回手机并闭眼。

带新玩家时，第一夜可以放慢节奏，确保大家理解流程。

### 人数与角色

| 人数 | 体验 |
| ---- | ---- |
| 3–4 人 | 角色少，适合新手试玩 |
| 5–6 人 | 经典配置，信息量和时长平衡 |
| 7–8 人 | 角色多，夜晚流程更长，需要更多耐心 |

### 与阿瓦隆的选择

时间紧选一夜狼人，想深度体验选阿瓦隆。详见[场景选型](../scenarios.md)。

## 常见问题

### 有人偷看夜晚操作怎么办？

和谁是卧底一样，这是线下默契问题。建议第一局前先强调闭眼规则，违规只能重开。

### 没有真人主持人，流程会乱吗？

App 会逐步提示当前角色和下一步。带新玩家时第一局可能慢一些，第二局就会流畅很多。

### 角色太多记不住怎么办？

使用推荐角色包即可，不必一开始就启用全部扩展角色。当前版本会持续根据用户反馈优化角色组合。
