# 阿瓦隆

阿瓦隆是聚会助手里策略深度最高的游戏，适合 7–10 人饭后正式局。需要 5–10 分钟讲解规则，但小程序会承担发牌和流程提示，降低主持负担。

## 适合场景

- **人数**：7–10 人为宜，最低 5 人；
- **时长**：单局约 30–45 分钟；
- **氛围**：推理、说服、演技；
- **新手友好度**：★★☆☆☆（需要讲解）

## 规则速览

玩家分为好人阵营（梅林、派西维尔、忠臣）和坏人阵营（莫德雷德、莫甘娜、刺客等）。好人需要通过任务投票找出坏人，坏人需要破坏任务并在最后刺杀梅林。

聚会助手负责：身份发放、任务队伍选择提示、投票记录和刺杀环节。**讨论、发言和投票发生在桌面上**。

## 完整使用流程

### 1. 进入游戏

首页点击 **阿瓦隆** → 进入设置页。

### 2. 调整设置

| 设置项 | 说明 |
| ------ | ---- |
| 玩家人数 | 5–10 人，角色组合随人数自动分配 |
| 角色配置 | 使用推荐角色包，适合对应人数 |

如果已在[聚会设置](../party-settings.md)填写了 4 人以上姓名，默认人数会自动同步（最低 5 人）。

### 3. 开始发牌

点击「开始发牌」→ 进入传手机环节。

### 4. 传手机查看身份

流程与谁是卧底类似：

1. 按座位号顺序传递手机；
2. 每位玩家**长按屏幕**查看自己的身份和相关信息；
3. 松手后信息隐藏；
4. 全部看完后进入主持面板。

不同身份看到的信息不同（例如梅林知道部分坏人，派西维尔看到梅林和莫甘娜但分不清）——这些规则在发牌时由 App 展示。

### 5. 桌面游戏

身份发放后，面对面进行阿瓦隆的标准流程：

1. **选队长**：轮流选队长组任务队伍；
2. **组队投票**：全员投票是否同意队伍；
3. **执行任务**：队伍成员私密投成功/失败；
4. **重复**直到好人完成 3 次任务或坏人破坏 3 次；
5. **刺杀梅林**：若好人完成任务，刺客猜测谁是梅林。

### 6. 主持面板

小程序主持面板辅助记录流程：

| 操作 | 说明 |
| ---- | ---- |
| 查看身份 | 长按玩家方块查验（仅主持用途） |
| 任务推进 | 按轮次记录队伍选择和任务结果 |
| 忘词/忘身份回看 | 点击玩家方块临时查看 |
| 刺杀环节 | 引导刺客选择目标 |
| 再开一局 | 保留人数和角色配置 |

### 7. 结算

- 显示好人或坏人获胜；
- 可查看关键回合回顾；
- 再开一局或返回首页换游戏。

## 新手讲解建议

阿瓦隆是四款游戏里规则最重的，建议开局的玩家花 5–10 分钟讲解核心概念：

### 必须讲清楚的 3 件事

1. **两个阵营**：好人要让任务成功并保护梅林；坏人要破坏任务并找出梅林。
2. **任务投票**：每轮选人去执行任务，队伍里的人私密投成功或失败——坏人可以投失败。
3. **刺杀**：即使好人完成 3 次任务，刺客猜中梅林则坏人仍赢。

### 可以稍后解释的细节

- 梅林可以看到部分坏人但不能暴露自己；
- 派西维尔看到两个人但分不清谁是谁；
- 莫德雷德对梅林隐身。

### 第一局建议

- 7 人局角色最少，适合新手；
- 主持人在主持面板辅助记流程，自己也可以参与讨论；
- 第一局允许犯错，不必追求完美。

## 使用技巧

### 提前填姓名

7–10 人局强烈建议在[聚会设置](../party-settings.md)填写姓名。阿瓦隆讨论时频繁提到「几号」「谁跟谁一队」，有姓名效率高很多。

### 环境要求

- 需要 30–45 分钟不被打断；
- 桌面空间够放手机即可，不需要实体卡牌；
- 饭后桌面清空时是最佳时机。

### 与一夜狼人的选择

| 维度 | 阿瓦隆 | 一夜狼人 |
| ---- | ------ | -------- |
| 人数 | 7–10 人最佳 | 3–8 人 |
| 时长 | 30–45 分钟 | 20–30 分钟 |
| 复杂度 | 较高，多轮任务 | 中等，一晚定胜负 |
| 适合 | 想认真玩一局 | 时间有限但想推理 |

## 常见问题

### 5 人能玩吗？

可以，最低 5 人。但 7 人以上体验更接近经典阿瓦隆。

### 主持人需要知道所有身份吗？

不需要。App 主持面板可以查验身份，但建议只在必要时使用。理想情况下所有人都参与推理。

### 坏人破坏任务时怎么操作？

队伍成员在 App 里私密投成功/失败，其他玩家不应偷看屏幕。
