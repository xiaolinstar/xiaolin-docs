# 谁是卧底

谁是卧底是聚会助手里最轻量的游戏，4 人即可开局，规则 1 分钟能讲完，适合等菜、热场和朋友小聚。

## 适合场景

- **人数**：4–7 人最佳，最多支持 20 人；
- **时长**：单局约 10–20 分钟；
- **氛围**：热闹、讨论多、不怕吵；
- **新手友好度**：★★★★★

## 规则速览

每位玩家拿到一个词语，其中 1–2 位「卧底」拿到的词与其他人略有不同。玩家轮流描述自己的词（不能直接说出），通过讨论和投票找出卧底。卧底如果在被找出前猜中平民的词，也算获胜。

聚会助手负责：分配身份、展示词语、主持投票和结算。**描述和讨论发生在桌面上**，不需要在 App 里输入。

## 完整使用流程

### 1. 进入游戏

首页点击 **谁是卧底** → 进入设置页。

### 2. 调整设置

| 设置项 | 说明 |
| ------ | ---- |
| 玩家人数 | 4–20 人，卧底数量随人数自动调整 |
| 词对选择 | 默认「随机抽取（推荐）」，也可手动选词或添加自定义词对 |

点击词对区域可进入词库页：

- 按平民词、卧底词或标签搜索；
- 选择内置词对；
- 添加自定义词对（仅保存在本机）；
- 删除自己添加的自定义词对。

### 3. 开始发牌

点击「开始发牌」→ 进入传手机环节。

### 4. 传手机查看词语

流程：

1. 把手机递给 1 号玩家；
2. 玩家**长按屏幕**查看自己的词语和身份（平民 / 卧底）；
3. 松手后信息隐藏；
4. 递给 2 号、3 号……直到最后一位玩家看完；
5. 最后一位看完后自动进入主持面板。

::: tip
如果已在[聚会设置](../party-settings.md)填写姓名，界面会显示「张三（3 号）」。
:::

### 5. 桌面讨论

所有人看完词语后，面对面轮流描述。聚会助手不提供描述输入框——这是刻意的，线下交流才是游戏主体。

### 6. 主持面板

传手机环节结束后进入主持面板，主持人（通常是最后看完词语的人，或大家推举的人）用手机操作：

| 操作 | 方式 |
| ---- | ---- |
| 查验玩家身份 | **长按**玩家方块，松手前可看到身份 |
| 查看玩家词语 | **点击**玩家方块，打开忘词回看 |
| 忘词回看 | 在弹出层中**长按**可临时显示词语 |
| 记录投票结果 | 按流程标记出局玩家 |
| 提交词对反馈 | 本局结束后评价词对质量 |

### 7. 结算与再开一局

- 显示胜负结果（平民找出卧底，或卧底猜中平民词）；
- 可提交词对反馈：**太容易猜** / **太难描述** / **刚刚好**；
- 点击「再开一局」保留当前人数和词对设置。

## 词库与反馈

### 随机 vs 手动选词

- **随机抽取（推荐）**：从内置词库随机配对，适合大多数场景；
- **手动选择**：适合想控制难度或主题的聚会；
- **自定义词对**：自己添加词对，保存在本机，不会上传词语全文。

### 词对反馈

主持面板结算时可提交反馈，帮助改进词库：

- 太容易猜：词语差异太明显；
- 太难描述：两个词太接近或太冷门；
- 刚刚好：难度适中。

反馈以匿名方式上报（只含词对编号和原因，不含词语内容），网络失败时本地记录，不影响游戏。

## 使用技巧

### 热场连开

谁是卧底单局短，适合连开 2–3 局。再开一局会保留人数设置，换词只需重新选词或继续随机。

### 人数建议

| 人数 | 卧底数 | 体验 |
| ---- | ------ | ---- |
| 4–5 人 | 1 卧底 | 节奏快，适合新手 |
| 6–7 人 | 1–2 卧底 | 经典配置 |
| 8 人以上 | 自动调整 | 讨论环节更长，需要控场 |

### 主持建议

- 查验身份时长按保持 secrecy，不要在他人视线内长按太久；
- 忘词回看是给描述时忘记词语的玩家用的，不要滥用；
- 投票环节可以让大家举手或口头表决，主持人在 App 里记录结果。

## 常见问题

### 有人偷看了怎么办？

传手机时其他玩家应移开视线。如果发生偷看，只能重开一局——这是线下游戏的默契，App 无法技术防范。

### 自定义词对会同步给别人吗？

不会。自定义词对仅保存在本机。

### 可以不看身份只看词语吗？

发牌时长按会同时显示词语和身份（平民/卧底），这是发牌器的设计——线下传手机时只有当前玩家能看到屏幕。
