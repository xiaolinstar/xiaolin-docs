# 场景选型：什么聚会玩什么

聚会前最难的决定往往不是「玩不玩」，而是「玩什么」。这一篇从人数、氛围、时长三个维度，帮你快速选对游戏。

## 快速决策表

| 你的情况 | 推荐游戏 | 理由 |
| -------- | -------- | ---- |
| 等菜、人还没到齐、想热场 | [谁是卧底](./games/undercover.md) | 4 人就能开，规则 1 分钟讲完 |
| 饭后 7–10 人，愿意听规则 | [阿瓦隆](./games/avalon.md) | 策略和演技空间大，适合正式局 |
| 3–8 人，想玩推理但时间有限 | [一夜狼人](./games/one-night-werewolf.md) | 一晚定胜负，App 自动主持夜晚流程 |
| 2–12 人，冷场需要破冰 | [真心话大冒险](./games/truth-or-dare.md) | 上手零门槛，轮流抽卡互动 |
| 有人完全没玩过桌游 | 谁是卧底 或 真心话大冒险 | 规则最轻，挫败感低 |
| 桌游老手想认真玩一局 | 阿瓦隆 或 一夜狼人 | 推理深度更高 |

## 按人数选型

### 2–3 人

选择有限，推荐：

- **真心话大冒险**：支持 2 人，轮流抽题互动。
- 谁是卧底、阿瓦隆、一夜狼人的人数下限分别为 4、5、3 人，人数不够时不建议硬开。

### 4–6 人

适合轻松局：

- **谁是卧底**（4–7 人最佳）：几分钟开局，适合小客厅、饭店包间。
- **一夜狼人**（3–8 人）：如果有人熟悉狼人杀规则，可以尝试。
- **真心话大冒险**：任何人数都能加入。

### 7–10 人

适合饭后正式局：

- **阿瓦隆**（7–10 人为宜）：身份隐藏 + 任务投票，需要一定讲解时间。
- **谁是卧底**：人数多时卧底数量会自动调整，仍然适合热场。
- **一夜狼人**：8 人局角色组合更丰富。

### 10 人以上

聚会助手当前聚会设置最多支持 10 个玩家姓名。超过 10 人时：

- **真心话大冒险**仍然适合大圈破冰（最多 12 人）；
- 桌游类建议分组开两桌，或让部分人先玩、轮换参与。

## 按聚会阶段选型

一场典型聚会往往有时间节奏，可以这样安排：

```text
到达 / 等菜        →  真心话大冒险 或 谁是卧底（热场）
饭菜进行中         →  轻松聊天，不必强行开局
饭后桌面清空       →  阿瓦隆 或 一夜狼人（正式局）
散场前             →  真心话大冒险（轻松收尾）
```

### 等菜 / 人没到齐

- 优先 **真心话大冒险** 或 **谁是卧底**；
- 不需要桌面空间，站着坐着都能玩；
- 有人迟到可以直接加入下一局。

### 饭后正式局

- 优先 **阿瓦隆** 或 **一夜狼人**；
- 需要 20–40 分钟不被打断；
- 建议提前在[聚会设置](./party-settings.md)填好玩家姓名，方便对号入座。

### 散场破冰

- **真心话大冒险** 轻松模式；
- 避免开需要复杂讲解的游戏，以免散场时仓促。

## 按氛围选型

### 想热闹、不怕吵

- **谁是卧底**：讨论环节容易吵起来，气氛最活跃。
- **真心话大冒险**（大冒险模式）：有肢体动作挑战时更热闹。

### 想动脑、重推理

- **阿瓦隆**：阵营对抗 + 任务投票，需要观察和说服。
- **一夜狼人**：夜晚身份变化 + 白天推理，信息量大。

### 想轻松、怕尴尬

- **真心话大冒险**（轻松风格 + 真心话模式）：题目经过审校，全部 `risk=safe`。
- **谁是卧底**：不涉及个人隐私，只讨论词语。

### 有新手 / 有老手混合

推荐开局顺序：

1. 先用 **谁是卧底** 或 **真心话大冒险** 暖场；
2. 有人提出「想玩正式的」再开 **阿瓦隆** 或 **一夜狼人**；
3. 开阿瓦隆前预留 5–10 分钟讲规则。

## 按时长选型

| 游戏 | 单局大约时长 | 适合场景 |
| ---- | ------------ | -------- |
| 谁是卧底 | 10–20 分钟 | 等菜、间隙、连开多局 |
| 真心话大冒险 | 不限（随时可停） | 碎片时间、灵活收尾 |
| 一夜狼人 | 20–30 分钟 | 饭后一局定胜负 |
| 阿瓦隆 | 30–45 分钟 | 饭后正式局，不建议赶时间时开 |

## 组合玩法建议

一场 3 小时的聚会可以这样组合：

```text
19:00  到场，真心话大冒险破冰（15 分钟）
19:30  上菜，暂停游戏
20:00  饭后谁是卧底热场（2 局，约 30 分钟）
20:30  阿瓦隆正式局（1 局，约 40 分钟）
21:10  散场前真心话大冒险收尾（10 分钟）
```

不必一次玩遍所有游戏，**选 1–2 款玩透** 比每款浅尝辄止体验更好。
