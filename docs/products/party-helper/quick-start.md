# 快速上手

这一篇帮你在 3 分钟内完成第一次开局。聚会助手不需要注册登录，打开微信小程序即可使用。

## 打开小程序

在微信中搜索并打开：**我的聚会助手**

首页会展示四款游戏的卡片，每张卡片包含：

- 游戏名称与一句话描述；
- 推荐人数与上手难度；
- 适合场景的简短说明。

底部有两个轻量入口：

- **聚会设置**：为本场聚会填写玩家姓名（可选）；
- **反馈与建议**：提交体验问题或内容建议。

## 通用开局流程

无论玩哪款游戏，流程都遵循同一模式：

```text
首页选游戏 → 设置人数和选项 → 开始发牌/抽卡 → 传手机查看私密信息 → App 引导讨论/投票 → 结算 → 再开一局
```

### 第一步：选择游戏

根据聚会情况选择游戏。不确定时，先看[场景选型](./scenarios.md)。

### 第二步：调整设置

每款游戏的设置页略有不同，但通常可以调整：

- **玩家人数**：加减按钮调整，人数会影响角色分配或卧底数量；
- **游戏选项**：如词库选择、真心话/大冒险模式、风格标签等。

设置页不会要求填写玩家姓名——姓名在[聚会设置](./party-settings.md)中统一管理。

### 第三步：开始游戏

点击「开始发牌」「开始游戏」等按钮后，进入传手机环节。

### 第四步：传手机查看

这是聚会助手的核心交互：

1. 把手机递给当前玩家；
2. 玩家**长按屏幕**查看自己的词语或身份；
3. 松手后信息隐藏；
4. 递给下一位玩家，直到所有人看完。

::: tip 线下配合
传手机时，其他玩家建议暂时移开视线或聊天 distraction，避免偷看。这是线下聚会的默契，不是 App 能完全替代的。
:::

### 第五步：按 App 引导推进

不同游戏后续流程不同：

- **谁是卧底 / 阿瓦隆**：进入主持面板，长按查验身份、记录投票；
- **一夜狼人**：App 引导夜晚闭眼、角色行动、白天讨论和投票；
- **真心话大冒险**：轮流抽卡，完成挑战或选择跳过。

### 第六步：结算与再开一局

一局结束后可以：

- 查看胜负结果；
- 提交内容反馈（词对好不好、题目合不合适）；
- 一键再开一局，人数和设置会保留。

## 可选：聚会前填写玩家姓名

如果聚会人数 ≥ 4 且大家互相认识，建议开局前花 1 分钟填写姓名：

1. 首页底部点击 **聚会设置**；
2. 为每位玩家填写姓名（最多 10 人）；
3. 点击 **保存设置**。

保存后发牌和主持界面会显示「张三（3 号）」而不只是「玩家 3」，线下传手机和对号入座更自然。

详细说明见[聚会设置](./party-settings.md)。

## 分享与邀请

聚会助手支持微信分享，可以把游戏入口分享给朋友：

- 分享后好友点击会进入对应游戏设置页；
- 适合聚会前提前发到群里，让大家知道今晚用什么工具；
- 分享不需要对方安装额外 App，微信小程序即可打开。

## 常见问题

### 需要联网吗？

核心游戏流程**不需要联网**。单机发牌、传手机、主持面板都在本地完成。

只有以下场景可能访问网络：

- 提交内容反馈（失败时静默降级，不影响游戏）；
- 真心话大冒险开局事件上报（同样失败不影响游戏）。

### 需要登录吗？

不需要。打开小程序即可使用全部游戏功能。

### 多人需要各装一个吗？

不需要。一台手机传着玩即可，这是产品设计的前提。

### 玩家姓名会泄露吗？

不会。姓名仅保存在本机，当天有效，次日自动清空，不上传服务器。详见[隐私与反馈](./privacy-feedback.md)。

### 某款游戏人数不够怎么办？

每款游戏有最低人数要求：

| 游戏 | 最低人数 |
| ---- | -------- |
| 谁是卧底 | 4 人 |
| 阿瓦隆 | 5 人 |
| 一夜狼人 | 3 人 |
| 真心话大冒险 | 2 人 |

人数不足时建议换一款游戏，或等更多朋友到齐。
