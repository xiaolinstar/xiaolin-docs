# 聚会助手产品理念

聚会助手不是把线下桌游「搬到线上对战」，而是为**真实聚会场景**设计的一台设备发牌器：手机在桌上传递，玩家面对面交流，小程序只负责发牌、控流程、提示下一步。

## 设计初衷

### 从真实聚会痛点出发

朋友聚餐、家庭聚会、同事小聚时，大家常常想玩点什么，但往往会卡在这些问题上：

- **没人愿意当主持人**：发牌、记流程、控节奏都要占用一个人，这个人就没法正常参与游戏。
- **规则讲解成本高**：阿瓦隆、一夜狼人这类游戏，新手第一次玩往往要听 10 分钟以上规则。
- **开局路径分散**：谁是卧底、阿瓦隆、破冰游戏各自独立，每次都要重新找 App 或道具。
- **一台设备就够**：多数聚会只有一部手机愿意拿出来传着玩，不需要每人装 App、建房间、连 Wi-Fi。

聚会助手的设计初衷，就是把这些摩擦降到最低：**让聚会里最容易发生的「想玩但懒得折腾」变成「点开就能玩」。**

### 一台设备，传着玩

这是聚会助手最核心的产品假设：

```text
一台手机 → 轮流传递 → 玩家私密查看自己的信息 → 面对面讨论和投票 → 小程序提示下一步
```

这意味着：

- **不需要多人实时联网**：没有房间号、没有等待队友上线、没有网络延迟。
- **不需要账号登录**：打开小程序就能用，不强制微信授权个人信息。
- **主持人由 App 承担**：发牌、夜晚流程、任务推进由小程序引导，所有人都参与游戏。
- **线下交流是主体**：小程序是辅助工具，讨论、演技、投票发生在真实桌面上。

### 所有人都参与，不牺牲一个主持人

一夜狼人等游戏在经典玩法里常需要一名真人主持人，但主持人往往知道大量信息，无法正常参与推理。

聚会助手选择 **App 自动主持** 模式：

- App 负责提示「现在轮到预言家行动」「请所有玩家闭眼」；
- 只有当前行动的玩家拿起手机做私密操作；
- 其他玩家通过闭眼避免看到操作过程；
- 没有人因为「要主持」而被排除在游戏之外。

这不是让 App 替玩家做决定，而是让 App 承担流程引导，玩家仍然自己做选择。

## 产品边界

聚会助手明确聚焦 **线下聚会游戏发牌器**，因此刻意不做这些事：

| 不做 | 原因 |
| ---- | ---- |
| 多人在线对战房间 | 与「一台设备传着玩」的核心场景冲突 |
| 账号体系与玩家档案 | 增加隐私和运营复杂度，聚会场景不需要 |
| 强制登录与社交关系链 | 降低使用门槛，保护聚会隐私 |
| 聚餐投票、生活决策工具 | 会模糊「聚会游戏」定位，暂缓作为主线 |
| 内置聊天、语音、视频 | 线下已经面对面，不需要在 App 里再建一套社交 |
| 重度版权桌游完整复刻 | 聚焦规则可自研、适合发牌器模式的游戏 |

### 新游戏筛选标准

每款新游戏进入聚会助手前，需要满足：

- 适合一台手机完成流程；
- 不依赖多人实时联网；
- 可以通过传手机完成私密信息查看；
- 规则不宜过重，新玩家能在短时间理解；
- 一局时长可控，适合饭后或等菜间隙；
- 不需要地图、支付或外部内容平台。

聚餐投票等「生活工具」类方向曾评估过，但当前不作为主线，避免产品边界膨胀。

## 体验设计原则

### 快速开局优先

玩家姓名、词库选择等能力是**辅助功能**，不作为开局阻塞项。未填写姓名时显示「玩家 N」，老用户习惯不受影响；填写姓名后显示「姓名（N 号）」，方便线下对号入座。

### 本地优先，隐私克制

- 玩家姓名仅保存在本机，当天有效，次日自动清空；
- 游戏身份、词语、投票结果不上传服务端；
- 内容反馈只上报匿名编号和原因，不含可识别个人身份的信息。

### 内容可运营

真心话大冒险题库、谁是卧底词库需要持续优化。产品提供「这题不合适」「词对太难描述」等轻量反馈入口，让用户帮助改进内容，而不是只靠开发者拍脑袋。

### 高产品一致性，低代码耦合

多款游戏共享一个游戏大厅、一套聚会设置、一套视觉和交互词汇，但每款游戏的规则独立成模块，避免「改一个游戏弄坏另一个」。

## 与同类产品的差异

| 维度 | 聚会助手 | 常见线上桌游 App |
| ---- | -------- | ---------------- |
| 使用场景 | 线下面对面聚会 | 远程联机或单人练习 |
| 设备需求 | 一台手机传着玩 | 每人一部手机 |
| 网络需求 | 单机为主，反馈可离线降级 | 通常需要稳定联网 |
| 主持人 | App 自动主持 | 常需指定真人主持或系统托管 |
| 账号 | 无需登录 | 通常需要注册登录 |

## 长期方向

聚会助手以微信小程序为当前主平台，长期演进方向包括：

- 更多适合发牌器模式的聚会游戏（如海龟汤主持器等）；
- Web/H5、原生 App 等平台壳层，共享同一套游戏规则；
- 房间、账号、同步等服务能力——仅在多游戏、多平台真正需要时再引入。

当前阶段优先把微信端的四款核心游戏体验和内容质量打磨到位。

## 总结

聚会助手的本质，是一个**为线下聚会减负的发牌与流程工具**：

- 理解自然交流发生在桌面上，而不是在 App 里；
- 用一台设备降低开局和主持成本；
- 用克制的产品边界避免变成泛娱乐平台；
- 用匿名反馈让内容可以持续变好。

如果你认同「聚会时想玩、但不想折腾」这个场景，聚会助手就是为此设计的。
