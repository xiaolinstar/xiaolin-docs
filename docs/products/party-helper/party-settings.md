# 聚会设置

聚会设置让你为本场线下聚会填写玩家姓名，发牌和主持界面会显示「姓名（N 号）」而不只是「玩家 N」。这是可选功能，不填写也能正常开局。

## 入口位置

首页底部 → **聚会设置**

与「反馈与建议」并列，属于轻量辅助入口，不会阻塞游戏开局。

## 能做什么

### 填写玩家姓名

- 默认展示 **7 个**输入位；
- 可点击「添加玩家」扩展到最多 **10 个**；
- 每位玩家最多 12 个字符，自动去除首尾空格；
- 未填写的座位仍显示「玩家 N」。

### 同步游戏默认人数

保存时如果填写了 **4 个及以上**姓名，会自动同步为下一局游戏的默认人数：

- 谁是卧底：按已填写姓名数量同步；
- 阿瓦隆：最低 5 人，填写 4 个姓名时仍按 5 人局开始；
- 其他游戏会读取已保存的人数偏好。

页面上会实时提示当前填写状态和同步结果，例如：

- 「可选填写，次日自动清空。」
- 「已填写 4 位，保存后同步默认人数。」

### 清空姓名

点击「清空姓名」会二次确认，避免误触。清空后：

- 只清除本场聚会姓名；
- **不影响**已经开始的游戏进度；
- 各游戏设置页恢复显示「玩家 N」。

## 使用建议

### 什么时候值得填写

| 场景 | 建议 |
| ---- | ---- |
| 7–10 人饭后正式局 | 强烈建议填写，方便对号入座 |
| 4–6 人朋友小聚，互相认识 | 建议填写，传手机时更好辨认 |
| 2–3 人或不认识的人多 | 可不填，用座位号足够 |
| 连开多局同一批人 | 填一次，多局复用 |

### 填写顺序

姓名与座位号一一对应：

- 1 号座位 = 第一个输入框；
- 建议按桌面顺时针或实际座位顺序填写；
- 线下可以口头确认「我是 3 号」后再开始发牌。

### 与游戏设置页的关系

各游戏的设置页（人数、模式、词库等）**不包含**姓名输入，保持快速开局路径简洁。

流程建议：

```text
聚会设置（填姓名，可选）→ 首页选游戏 → 游戏设置页（调人数）→ 开始
```

## 数据存储规则

### 仅存本地

- 姓名保存在本机微信客户端的本地存储中；
- **不上传**到开发者服务器；
- **不关联**微信 OpenID、昵称或头像。

### 当天有效

- 姓名在填写当天有效；
- **次日自动清空**，不会长期保留玩家档案；
- 这是刻意的隐私设计，避免聚会助手变成「社交关系数据库」。

### 不跨设备同步

- 换一部手机需要重新填写；
- 同一部手机上卸载或清空小程序缓存后，姓名也会丢失。

## 设计原则

聚会助手对玩家姓名的态度是 **辅助而非必需**：

1. **不阻塞开局**：未填姓名时一切功能正常，显示「玩家 N」；
2. **保留座位号**：即使填了姓名，仍显示「姓名（N 号）」，方便线下传手机和主持记录；
3. **不做账号体系**：没有「常用玩家名单」「好友列表」等长期档案；
4. **当天清空**：聚会结束第二天自动重置，降低隐私顾虑。

## 常见问题

### 填了姓名但游戏里还是显示「玩家 N」？

检查是否点击了「保存设置」并看到成功提示。保存后返回首页再进入游戏。

### 人数和姓名数量不一致怎么办？

游戏设置页仍可独立调整人数。姓名按座位号对应，超出姓名数量的座位显示「玩家 N」。

### 可以只填部分人的姓名吗？

可以。填了几个就显示几个，其余仍显示「玩家 N」。

### 姓名会被发到网上吗？

不会。详见[隐私与反馈](./privacy-feedback.md)中的本地存储说明。
