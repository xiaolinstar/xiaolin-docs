# 聚会助手（Party Helper）

聚会助手是一款面向线下聚会场景的微信小程序，把谁是卧底、阿瓦隆、一夜狼人、真心话大冒险等经典桌游和破冰游戏整合进统一的游戏大厅，帮助朋友小聚时快速开局、自动主持、减少讲解成本。

微信小程序官方名称为「我的聚会助手」，英文项目名为 `party-helper`。

## 一句话理解

**一台手机，传着玩，不用联网房间，也不用有人专门当主持人。**

**聚会前 5 分钟**：先看[场景选型](./scenarios.md)，确定今晚玩什么。

**第一次打开小程序**：直接看[快速上手](./quick-start.md)，再按游戏进入对应指南。

**想理解产品思路**：看[产品理念](./product.md)。

**准备正式局（7 人以上）**：建议提前看[聚会设置](./party-settings.md)，给玩家填上姓名。
