**奶茶仙人**是一款帮助城市白领管理奶茶热量摄入的轻量工具，在「奶茶自由」与「热量焦虑」之间提供清晰的数据视角，核心价值是让喝奶茶不再成为「罪恶感」的来源，而是一种「有控制的享受」。

---

## 功能模块总览

奶茶仙人围绕「记录 — 预算 — 选择 — 回顾」这一闭环组织功能，覆盖用户端与运营端两条主线：

| 模块 | 面向对象 | 核心能力 |
| :--- | :--- | :--- |
| **热量打卡** | 用户 | 快速记录当日饮品，实时累计摄入与剩余预算，超标视觉警示。 |
| **预算配置** | 用户 | 设置每日/每周热量上限，支持 kcal 与 kJ 双单位切换并本地持久化。 |
| **饮品库检索** | 用户 | 按品牌、品类、评级检索饮品，直观展示热量、糖分、脂肪与 ABCD 评级。 |
| **历史回顾** | 用户 | 按周/月回溯饮用量与每日均值，支持删除误记录。 |
| **品牌与菜单运营** | 运营 | 维护品牌档案、录入饮品成分、补齐数据来源与凭证。 |
| **审核与发布** | 管理员 | 批次流水化审核，控制饮品上线与状态流转。 |

## 核心定位与用户故事

### 用户角色定义

- **续命打工人**：每天需要咖啡或奶茶提供工作动力，但希望精准控制每日的糖分和热量摄入。
- **健身/控卡爱好者**：执行严格的饮食管理，偶尔允许自己「放纵一下」，需要透明的数据支持以做出相对健康的饮品选择。

### 核心用户故事 (User Stories)

- **US-1：记录今日饮品**：作为用户，我能快速记录今天喝的奶茶。系统会在首页展示「今日已喝」列表、累计摄入热量以及剩余热量预算。当热量超标时，主界面会触发视觉警示。
- **US-2：热量预算配置**：用户可自行设置每日或每周的热量预算上限（默认为 2000 kcal），并支持在千卡（kcal）与千焦（kJ）之间无缝切换，设置后本地自动持久化保存。
- **US-3：饮品浏览与筛选**：用户可以根据饮品品牌、品类进行智能搜索，产品列表中将直接呈现热量、糖分、脂肪及评级信息，并支持按评级筛选（A 级饮品优先展示）。
- **US-4：健康替代推荐**：当用户选中一款高热量（C/D 级）饮品时，系统会在同品牌或同品类中推荐评级更优、热量更低的替代选项，辅助用户在「想喝」与「少负担」之间做出决策。
- **US-5：饮用历史回顾**：支持按周或按月回溯历史饮用量，直观查看累计热量与每日平均值，支持删除错误记录。

## 数据运营与管理故事 (Admin Stories)

为了支撑前端精准的产品库数据，「奶茶仙人」设计了一套严谨的**数据运营工作流**（AUS-1 至 AUS-6）：

- **AUS-1：品牌档案管理**：管理员可以建立茶饮品牌档案，维护官方入口、数据来源备注，并设置品牌状态（草稿/在售/停售）。
- **AUS-2：菜单占位录入**：支持运营人员先行导入未标明热量的占位饮品（标记为 `nutritionAvailable=false` 并置为 `pending` 状态）。在用户侧这类产品会显式展示「热量待完善」，禁止作为认证热量直接记录。
- **AUS-3：数据来源补齐**：为了保证数据的真实与权威，录入的每项营养数据都必须补齐来源链接、采集时间和凭证截图，未录入来源的饮品无法通过审核。
- **AUS-4：批次审核与发布**：审核人员会通过数据看板对特定批次进行流水化审核。非管理员不能执行最终的发布上线操作。
- **AUS-5：数据看板与统计**：运营人员可在管理端查看饮品覆盖率、待完善数量、各评级占比等指标，快速定位需要补齐来源或复核的饮品。
- **AUS-6：角色与权限控制**：系统区分运营、审核、管理员三类角色，录入、审核、发布分权把控，关键操作留痕以保证数据可追溯。

## 营养评级标准

项目严格参考**新加坡食品评级标准 (Nutri-Grade)** 制定了 A / B / C / D 评级算法。评级阈值定义如下：

| 评级 | 热量 | 糖分 | 脂肪 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **A** | < 150 kcal | < 5 g | < 3 g | 最佳选择，无负担极佳体验 |
| **B** | < 250 kcal | < 10 g | < 5 g | 良好选择，成分相对健康 |
| **C** | < 350 kcal | < 20 g | < 8 g | 适量选择，建议搭配运动 |
| **D** | ≥ 350 kcal | ≥ 20 g | ≥ 8 g | 限量选择，一杯即达每日警戒线 |

> [!IMPORTANT]
> **计算约束**：营养评级采用「木桶效应」判定，即热量、糖分、脂肪三项指标必须**同时满足**对应阈值，只要有一项超标，产品评级就会自动落入下一档次。
