# 项目通用规则

- 始终使用中文回复用户，但技术专有名词可保留英文（如 API、Python、DTO等）。
- 使用项目既有风格，不引入新风格，包括代码、文档或交互，默认延用项目中已有的格式、缩进、命名习惯。
- 尽可能少地输出内容，仅提供高信息密度回复，禁止无效寒暄、过度铺垫，只输出对当前任务有直接帮助的信息。
- 遵守[《中文文案排版指北》](https://www.bookstack.cn/read/chinese-copywriting-guidelines/README.md)标准排版格式：中文与英文之间加空格，中文与数字之间加空格；全角标点与其他字符之间不加空格。全中文语境下必须使用全角标点。
- 在安装 Skill、Subagent、Commands、MCP、Hook 时，**项目 Skill 真源一律放在 `.agents/skills/`**（Agent Skills 标准目录，Codex / Antigravity / OpenCode 原生读取）。若目标工具只认 `.claude/skills/`（Claude Code、Cursor），在 `.claude/skills/<name>` 创建符号链接指向 `.agents/skills/<name>`，禁止维护双份真源。必须同步在项目根目录的 `skills-lock.json` 中登记（含 `source`、`sourceType` 等字段），防止依赖记录丢失。
- 文档命名规范：必须全部使用小写字母，文档名需与文章内容主题紧密契合，多个单词间使用 `-` 分隔。命名应精简，不超过 4 个词汇（单词），以 3 个词以内为宜。
- Markdown 语法与渲染兼容性检查：中文全角标点（特别是中文句号 `。`）可能阻断加粗标记（`**`）的解析导致渲染失败。必须在加粗语法的外部添加半角空格隔离（如 `文本 **加粗** 文本`），或者将标点符号包含在加粗语法内部（如 `**加粗句子。**`）来确保完全兼容。撰写文档后，应习惯性通过类似 `markdown-formatter` 技能修正此问题。
- 术语与知识库规范：领域术语以 `docs/glossary/` 为唯一释义真源。正文优先使用短码 `{{term:规范名或id}}`；构建期会对知识库词（含 aliases）做自动匹配。同一篇文章内，每个术语仅在**首次出现**时挂悬停释义并插入旁注，后续出现保持纯文本，避免重复提示。禁止再用直角引号「」作为术语机器锚点（避免与旧约定混淆）。一般引用、口语转述使用弯引号“”；嵌套用『』。新增术语须先入库（`id`/`term`/`definition`，可选 `aliases` 和 `en` 英文名）再在正文使用。禁止在 Markdown 链接文案或图片 alt 内使用 `{{term:…}}`（会破坏语义 / 交互）。
- **术语正文解释的唯一源头原则**：每个术语在全站只能有一个"首次正文解释"的源头文章，在该文章中可以用括号、文字等方式详细说明含义；其他所有文章只用 `{{term:xxx}}` shortcode 提供 hover，禁止在正文重复解释同一术语的含义。新增或修改文章时须检查该术语是否已在早于本篇的系列文章中被解释过，若已有源头，则本篇正文中删除重复的括号说明，仅保留 shortcode。
- 引号与加粗结合规范：弯引号与加粗并存时，加粗在引号内：`“**强调**”`。
- **代码块与行内代码的使用规范**：
  - **判断口诀**：能不能独立成段被读者复制 → fenced code block；嵌在句子里被读者读到 → 行内代码。
  - **fenced code block（```` ```bash ````）** 用于命令/脚本独立成段、可被读者直接复制执行。触发条件（满足其一）：
    1. 命令独立成段（前后空行包围）
    2. 命令是当前段的动作焦点（前面有"运行这条命令"、"执行以下"等引导）
    3. 多条命令组成一个完整步骤序列
    4. 命令较长或含特殊字符，必须复制粘贴才能正确执行
  - **行内代码（` `）** 用于命令/标识符作为名词或概念嵌入其他上下文：
    1. 在叙述句中作为名词或概念提及（如"使用 `scp` 命令"）
    2. 在有序/无序列表项中作为步骤说明的一部分（如"步骤 1：运行 `nginx -t`"）
    3. 在表格的某一列中
    4. 文件路径、目录名、文件名（无论上下文）
    5. 程序名、包名、配置项（如 `nginx`、`apt`、`sites-enabled/*`）
  - **典型边界**：单行命令若独立成段仍用 fenced（不要把它和叙述句里的同名命令混淆）；blockquote 内嵌的命令若独立成段，每行加 `>` 仍用 fenced。
