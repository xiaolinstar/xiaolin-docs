# 一源多用输出模板

Agent 完成 `content-repurpose` 后，按此结构写入 `content/dist/{slug}/`（见 [content/dist/README.md](../../../../content/dist/README.md)）。

---

## 文档头

```markdown
# 一源多用包：{标题}

- **源文件**：{path}
- **Slug**：{slug}
- **内容支柱**：Vibe Coding / 云原生 / 独立产品（选一或组合）
- **站点链接**：https://xiaolinstar.cn/{path}
- **生成日期**：{date}
- **目标平台**：{用户指定的平台列表}
```

## §1 公众号（AI持续运维）

由 **`wechat-publisher`** 从 Origin 生成，落盘 `content/dist/{slug}/wechat.md`。

结构见 [wechat-publisher/SKILL.md](../wechat-publisher/SKILL.md) 与范例 `content/dist/harness-engineering/wechat.md`：

```markdown
---
origin: docs/...
slug: ...
mode: repurpose | repurpose+polish
status: draft | ready | published
---

# 发布元数据（标题 ×3、摘要 80–120 字）

# 正文（可粘贴公众号后台）

# 文末引流

# 发布 checklist
```
